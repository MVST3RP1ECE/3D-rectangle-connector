# 3D Rectangle Connector (TypeScript)

Визуализация соединения двух прямоугольников с помощью ломаной линии на Canvas. Программа позволяет интерактивно перемещать прямоугольники и точки соединения, а также автоматически строит кратчайшую ломаную с учётом геометрии.

## Возможности

- Перетаскивание прямоугольников мышью
- Перетаскивание точек соединения по граням
- Автоматическая отрисовка ломаной линии между прямоугольниками
- Проверка корректности соединений (точка на грани, угол наружу)
- Покрытие основного алгоритма unit-тестами

## Структура проекта

```
├── src/
│   ├── app.ts                # Инициализация и логика приложения
│   ├── dataConverter.ts      # Главный алгоритм построения ломаной

│   │   ├── types.ts          # Типы данных (Point, Rect, ...)
│   │   └── rectUtils.ts      # Геометрические утилиты

│       ├── draw.ts           # Функции отрисовки на Canvas
│       └── interact.ts       # Drag&drop и hit-test
├── test/
│   └── dataConverter.test.ts # Unit-тесты для алгоритма
├── index.html                # HTML с Canvas
├── package.json              # Скрипты, зависимости
├── tsconfig.json             # Настройки TypeScript
└── README.md                 # Описание проекта
```

## Быстрый старт

1. Установите зависимости:
   ```bash
   npm install
   ```
2. Запустите проект в режиме разработки:
   ```bash
   npm start
   ```
   Откроется страница с Canvas, где можно перетаскивать прямоугольники и соединения.

## Тестирование

Для запуска unit-тестов:

```bash
npm test
```

## Архитектура и алгоритм

- **dataConverter** — функция, строящая ломаную между двумя прямоугольниками с учётом точек и углов соединения. Проверяет корректность входных данных, минимизирует количество изломов, избегает поворотов на 180°.
- **rectUtils** — геометрические проверки: принадлежность точки грани, направление угла, смещение по нормали и др.
- **draw** — отрисовка прямоугольников, ломаной и соединительных точек.
- **interact** — обработка drag&drop для прямоугольников и соединений.
